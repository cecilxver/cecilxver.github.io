
# Portfolio de Cecilia Serrano Martín

Mi portfolio personal: una web de una sola página, minimalista y en blanco y negro, donde reúno quién soy, mis habilidades, mis proyectos y mi currículum.

🔗 **Web:** [cecilxver.github.io](https://cecilxver.github.io)


## Qué incluye

- **Inicio:** presentación con efecto de escritura, botón de contacto y descarga del CV.
- **Sobre mí:** resumen personal y habilidades divididas en Backend y Frontend.
- **Proyectos:** pestañas para ver los proyectos *En curso* y *Completados*.
- **Currículum:** formación, experiencia y un apartado de texto libre.
- **Contacto:** correo y enlaces a mis redes.
- Diseño adaptable a móvil, tablet y escritorio.

## Tecnologías

- HTML5
- CSS3 (variables, grid y flexbox)
- JavaScript, sin librerías ni frameworks
- Tipografías de Google Fonts: Montserrat y Playfair Display
- Publicado con GitHub Pages

## Estructura del proyecto

```
cecilxver.github.io/
├── index.html   # La web completa (HTML, CSS y JS)
├── icon.png     # Retrato de la tarjeta de inicio
├── cv.pdf       # Currículum descargable
└── README.md
```

## Cómo verlo en local

1. Clona el repositorio:

   ```bash
   git clone https://github.com/cecilxver/cecilxver.github.io.git
   ```

2. Entra en la carpeta y abre `index.html` en el navegador. No necesita instalación ni servidor.
